# Исправления по результатам приёмки

## 22.11.2026 — публичные атрибуты доступны только для чтения

- **Классификация:** дефект реализации.
- **Ожидание SPEC:** раздел 3.3 разрешает чтение публичных атрибутов и требует
  менять состояние только методами класса.
- **Причина:** реализация D присваивала значения непосредственно публичным
  полям, поэтому вызывающий код мог менять энергию, позицию и параметры
  транспорта в обход методов.
- **Исправление:** состояние хранится во внутренних полях; публичные атрибуты
  представлены read-only свойствами. `move` и `refuel` меняют внутреннее
  состояние штатным путём.
- **Regression-тест:** TC-27 `test_public_attributes_are_read_only` проверяет
  невозможность присваивания всем публичным атрибутам и сохранение штатных
  обновлений через методы.
- **Проверка:** `python -m unittest discover -s tests -v` — 27 тестов прошли.
